# 局域网手机端

通过同一局域网的手机浏览器查看 League Akari 英雄数据。电脑切换英雄、模式、位置、地区、段位或版本后，手机会自动更新；手机上的英雄选择和筛选操作也会同步到电脑的英雄数据窗口。

## 开始使用

1. 电脑和手机连接同一路由器。电脑可以使用有线网络，手机使用 Wi-Fi。
2. 在 OP.GG 窗口标题栏点击「局域网手机端」，开启服务。也可以从主窗口侧栏或「设置 → 窗口管理 → 局域网手机端」进入。
3. 点击「二维码」，使用手机相机或浏览器扫码；或者点击「复制地址」，把完整地址在手机浏览器中打开。
4. 连接英雄联盟客户端后，在电脑选择英雄，手机会跟随显示对应推荐。手机从榜单选择英雄时，切换的是推荐页面。

默认端口为 **23946**，可在面板内修改。关闭后重新开启、修改端口或重启软件会更换访问凭据，需要使用最新地址或重新扫码。手机暂时断网、切到后台后，恢复网络或回到浏览器会自动重连。

## 手机显示

- **装备**：使用紧凑的多列网格，只显示图标和推荐序号。初始装备、鞋子、核心装备和后续装备分别编号。
- **强化符文**：固定 3 列显示图标、推荐序号和完整名称，为名称留出更多空间，可按品质筛选或搜索。海克斯乱斗按强度档位优先排列，同档位保留数据源的推荐顺序。
- **符文、召唤师技能、技能点法**：按分类查看；点击图标可打开说明。
- **筛选条件**：默认收起地区、段位、版本和位置，点击「筛选」展开，当前条件会显示在摘要中。

装备和强化符文列表省略胜率、登场率、场次、强度分数和受欢迎度。装备列表会根据手机宽度调整列数；强化符文在竖屏与横屏都保持 3 列。

## OP.GG 海克斯乱斗推荐

海克斯英雄排名和强化符文使用 OP.GG 的海克斯专属接口。召唤师技能、技能点法、初始装备、鞋子、核心装备和后续装备参考 OP.GG 最新版本的全球、全部段位普通大乱斗数据。电脑与手机均显示参考来源和实际版本，海克斯排名不会被普通大乱斗排名覆盖。

海克斯乱斗不展示普通符文配法，保留强化符文的图标、排名和名称，以及品质筛选。电脑端支持导入当前装备方案；手机端通过「装备」「召唤师技能」「技能点法」查看基础推荐，通过「强化符文」查看海克斯推荐。允许手机应用时，可应用召唤师技能。其他模式仍展示可用的普通符文配法。

普通大乱斗推荐暂时加载失败时，仍保留海克斯英雄与强化符文，并显示刷新重试提示；不会自动替换为其他数据源。

## 从手机应用符文与召唤师技能

电脑端「允许手机应用符文／技能」决定手机能否应用推荐。只有连接客户端、处于非观战的英雄选择阶段、推荐英雄与当前选择一致且模式匹配时，应用按钮才可用。

应用过程中也会检查英雄和推荐是否变化。符文页只使用可编辑的页面；召唤师技能遵循电脑端的闪现 D/F 设置。失败或部分成功时，手机会显示结果。

## Mini 窗口排名

选人区的当前英雄、备选英雄和可选英雄头像会显示当前游戏模式的 **OP.GG 排名**。排名独立于局域网服务加载，保留原有的左键、右键选人和换英雄操作。

排名使用当前模式、地区和段位偏好以及最新可用版本。没有 OP.GG 数据或模式不受支持时，头像不显示排名。

## 无法连接时

- 确认软件仍在运行，电脑和手机在同一局域网。多个地址对应不同网卡时，选择与手机相同网络的地址。
- 如面板提示端口占用，换一个端口后重新扫码。
- 如手机无法打开页面，检查 Windows 防火墙是否允许 League Akari 在专用网络通信。

## 本地开发

```sh
yarn install --immutable
yarn dev
```

`dev` 和 `build` 会先构建手机页面。开发手机页面时，在桌面开发程序启动后，可另开终端运行 `yarn dev:mobile`，再刷新手机浏览器。

```sh
yarn typecheck
yarn test
yarn build
yarn build:win
```

手机页面输出到 `out/mobile`，由主进程的局域网服务提供，并随 Windows 包一起分发。服务只公开手机页面、英雄数据、有限的导航与应用操作，以及图标资源。
